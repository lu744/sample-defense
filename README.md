# 🌱 保卫样地 · 延毕反击战

一个**草地生态学博士**视角的塔防小游戏。你是野外做实验的博士，邪恶势力为了让你「延毕」开始偷袭你的样地。你的任务：**放塔、打怪、守住样地、准时毕业**。

纯前端单文件实现，无需构建、无需联网，双击即可游玩。

---

## ✨ 玩法特色

- **卡牌制防御塔**：每张塔卡 = 一座塔（数量有限）。开局获得 3 张随身wifi + 2 张温度仪，放置消耗卡 + 金币，出售返还卡。
- **12 座防御塔**，每座可升到 3 级，3 级有**二选一分支**（选定不可逆），各带不同特效（溅射 / 灼烧 / 眩晕 / 秒杀 / 穿透 / 减速 / 光环 / 击退…）。
- **15 种敌人**，从土拨鼠、绵羊山羊（可跨铁门）、牛牛家族到最终 Boss 龙卷风，各有技能（冲刺 / 回血 / 返伤 / 复活 / 牛之力 / 风暴…）。
- **3 位主角**（开局锁定）：核动力牛马 / 佛系博士生 / 内向 i 人，各带不同加成与代价。
- **3 个难度**：发水刊 / 发一区 / 发 Nature。
- **连续关卡**：一局 = 随机地图 + 10 个连续关卡，地图与已放置的塔全程保留，敌人逐关变强；每关由玩家手动开始，可重开本关 / 暂停。
- **无尽模式**：通关 10 关后可进入，无上限，记录最佳波次。
- **科研技能**（12 种，可叠加）与**小卖部**（红牛 / 藿香正气水 / 维修工具 / 征地批文）。
- **怪物图鉴**：遇到过的怪物自动收录，可随时查看其数值、技能与描述。

## 🎮 操作说明

| 操作 | 说明 |
| --- | --- |
| 选塔 → 点击地图 | 放置防御塔（铁门放在**路径上**，其余放草地格） |
| 点击已放置的塔 | 查看详情 / 升级 / 出售 |
| 右键 / `Esc` | 取消选择 |
| 空格 | 暂停 / 继续 |
| 侧栏按钮 | 开始本关 · 小卖部 · 图鉴 · 重开本关 · 音乐开关 · 2x 速度 |

## 🛠 技术说明

- **纯前端**：HTML + CSS + JavaScript，无框架、无构建、无外部依赖。
- **渲染**：HTML5 Canvas 2D，`requestAnimationFrame` 主循环。
- **数据**：塔 / 敌人 / 技能 / 关卡波次全部以 JS 对象配置，改数值即可调整平衡。
- **图标**：由 AI 图像模型（Pollinations / Flux）生成，启动时预裁剪为圆形缓存。
- **图鉴 / 记录**：使用 `localStorage` 持久化。

### 自定义数值

- 塔、敌人、技能、难度、每关敌人构成等都在 `index.html` 内的对应配置对象里（`TOWERS` / `ENEMIES` / `SKILLS` / `DIFFS` / `LEVEL_ENEMIES`），直接改数字即可。
